3. Principes visuels validés

IdentitéE blanc, B bleu (variation bleu clair), fond bleu nuit, lignes de circuits électroniques, trois points de connexion, angles à 90° arrondis.
TraitFin et précis, cohérent avec les 103 pictogrammes déjà en place (viewBox 24×24, currentColor, stroke-width 1.6–2.2).
CouleurContraste blanc / bleu nuit / bleu électrique en base ; orange conservé comme seul accent secondaire, jamais dominant.
DégradéUn seul dégradé bleu, utilisé avec modération (halo discret derrière un point focal, jamais en fond plein).
Ce qu'on éviteRobots cartoon, personnages, 3D lourde, scènes isométriques, ombres réalistes, verre prononcé, halos multiples, texte dessiné dans le SVG, flou animé.
CohérenceAucun nouveau système de couleurs concurrent ; les illustrations complètent le langage existant, elles ne le remplacent pas.

4. Bibliothèque de composants

Petits pictogrammes factorisés en PHP (functions.php) et vocabulaire de construction des illustrations maîtresses. Voir aussi assets/images/illustrations/eb-flow/README.md.

Helpers PHP (utilisables dans les templates)

eb_tool_chevron(); // chevron de fin de puce outil — 35 usages factorisés
eb_contact_icon('phone', 14, '2'); // téléphone / email, header + audit
eb_icon('node' | 'validation' | 'circuit', 20, '1.8'); // registre étendu
eb_status_step($icon_svg, $label); // icône + libellé d'une étape de flux
eb_flow_connector(); // flèche entre deux étapes

Motifs des illustrations maîtresses

EB Circuit
Trace à angle droit, coin arrondi. Relie deux composants.
EB Node
Point de connexion rond, à chaque jonction d'un EB Circuit.
EB Data Card
Carte navy à coins arrondis, une icône centrée. Max 5/illustration.
EB Flow Connector
EB Circuit + 2 EB Node. Relie deux EB Data Card. Max 8/illustration.
EB Validation
Coche de confirmation, réservée aux cartes de résultat.
EB Master Illustration Container
Cadre général : viewBox 800×212, 3 zones (entrée → hub → résultat).
